#  Data-Driven Forecasting & Peak Demand Prediction for Afficionado Coffee Roasters

## About the Project

This project involves performing an in-depth exploration of coffee shop sales data to discover purchase patterns and predict sales. It uses historical sales data to determine peak hours and analyze trends within the sample data set. The project provides forecasts that can help the company make informed business decisions.

The project was executed using Python and includes an analysis of the data, feature engineering, machine learning implementation, and a dashboard for enhanced visualization and interaction with the data.
---

## Project Objectives

- Perform an exploratory data analysis of the given data.

- Identify peak hours and sales trends.
- Compare sales performance among different stores.
- Develop a sales forecast model.

- Visualize the results using a dashboard.
---

## Dataset
The dataset used for this project was collected from various coffee stores and contains information about each transaction that has taken place in these stores.

Some of the columns in the dataset include:
- Transaction ID
- Transaction Time
- Transaction Quantity
- Unit Price
- Store Location
- Product Category
- Product Type
- Product Detail

## Exploratory Data Analysis (EDA)
EDA was the first step in this project, and it involved visualizing the data to understand it better. Some of the key findings made at this stage were as follows:
- Insights into the general revenue distribution.

- The peak revenue hours based on time.
- Information on the categories of products sold.
- Stores' revenue distribution.
- Insights into quantities sold.
---
## Feature Engineering

Several features were engineered for this project, including revenue, hour, day, month, and weekday, to ensure the model was predictive.
---
## Machine Learning
A Machine learning model was developed to predict future sales based on past sales data. The following metrics were used to evaluate the model's performance:
- MAE
- RMSE
- R2 Score
---

## Key Insights
Some of the key insights that can be derived from this project include:
- Certain hours have a significantly higher sales volume.
- Certain stores appear to be more profitable than others.
- Certain product categories have higher sales volumes.
- Past sales data can be used to inform inventory management.
